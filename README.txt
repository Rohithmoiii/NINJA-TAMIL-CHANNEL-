NINJA TAMIL OFFICIAL - GitHub Pages landing page

Files:
- index.html: landing page
- logo.jpg: supplied logo

Publish:
1. Sign in to GitHub and create a PUBLIC repository, e.g. ninja-tamil-official.
2. Open the repository > Add file > Upload files.
3. Upload index.html and logo.jpg from this folder, then Commit changes.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for GitHub Pages deployment; use the Visit site link in Settings > Pages.

Meta Pixel:
Add the official Meta Pixel base code in the <head> where the comment says to add it. Telegram Join clicks call fbq Lead only if fbq is loaded. Verify with Meta Events Manager Test Events; this does not verify Telegram membership, only the click.
